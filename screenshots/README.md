# App Screenshots

These screenshots show all 6 screens of the Xi'an 90 Mandarin Practice app.

## 1. Today Screen
![Today Screen](1-today-screen.png)
- Countdown to December 12, 2026
- Daily lesson with story and vocabulary
- Practice lines and pronunciation tips
- Quick quiz preview

## 2. Speech Screen
![Speech Screen](2-speech-screen.png)
- All 14 lines of the commemoration speech
- Toggleable pinyin and English translations
- Per-line audio playback
- Shadowing mode and podium view

## 3. Record & Score Screen
![Record Screen](3-record-screen.png)
- Record each line with microphone
- Play back recordings
- Automatic syllable-level scoring (when supported)
- Visual feedback on pronunciation accuracy

## 4. Quiz Screen
![Quiz Screen](4-quiz-screen.png)
- Spaced repetition vocabulary drill
- Multiple quiz modes
- Session statistics
- Accuracy tracking

## 5. Archive Screen
![Archive Screen](5-archive-screen.png)
- Browse all daily lessons
- View completed days
- Access past lesson content

## 6. Progress Screen
![Progress Screen](6-progress-screen.png)
- Practice streak counter
- Per-line best scores
- Quiz statistics
- Export/import progress data

## Mobile First

These screenshots were captured at iPhone 12 Pro dimensions (390×844px) to show the mobile-first design. The app is fully responsive and works on all device sizes.

## Design

- **Color Palette**: Deep red (#8B0000), ivory (#FFFEF0), ink black (#1a1a1a)
- **Typography**: Noto Serif SC for Chinese text, Noto Sans SC for UI
- **Style**: Clean, respectful, Chinese-inspired aesthetic
